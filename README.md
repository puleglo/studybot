# StudyBot

Читает чаты учебной группы **с вашего аккаунта** (бот в группы не добавляется). Каждый вечер присылает в личного бота сводку за день. Учебные материалы (задания, методички, отчёты, решения одногруппников) раскладывает по предметам прямо в хранилище Obsidian через CouchDB (Self-hosted LiveSync).

```
Telegram (ваш аккаунт) ──читает──► studybot ──► SQLite (история)
                                     │  ├─► DeepSeek / любой OpenAI-совместимый API
                                     │  ├─► CouchDB ──LiveSync──► Obsidian: Учёба/<Предмет>/<Тип>/
                                     │  └─► бот ──► вам в личку: вечерняя сводка
SSH ──► studybot (панель в терминале)  — сетевых портов нет
```

## Что делает

- **Сводка:** каждый день в заданное время (по умолчанию 21:00) приходит отдельная сводка по каждому чату с разделами: ❗ важное (дедлайны, переносы, задания), 📚 по предметам, 📎 что скинули, 💬 прочее. Если сервер лежал в это время, сводка придёт, как только он поднимется.
- **Материалы:** файлы, фото и сообщения про задания (отбор по ключевым словам) классифицирует LLM с учётом контекста переписки. Результат раскладывается так:
  - `Учёба/Матанализ/Задания/2026-11-17 ДЗ 3.pdf`, сам файл;
  - `Учёба/Матанализ/Задания/2026-11-17 ДЗ по матану №3.md`, заметка: свойства (предмет, тип, дедлайн, кто прислал, ссылка на сообщение), краткое описание, исходный текст и встроенный файл.
  - Альбом из нескольких фото сохраняется одной заметкой. Новые предметы бот заводит сам, в панели их можно переименовать.
- **Команды бота** (отвечает только вам): `/summary`, `/today`, `/materials`, `/status`.
- **Аккаунт:** юзербот только читает. Он ничего не пишет и не отмечает сообщения прочитанными.

## Что понадобится

1. **VPS** с Debian/Ubuntu и Python 3.10 или новее.
2. **api_id / api_hash** с https://my.telegram.org → *API development tools*.
3. **Бот** из [@BotFather](https://t.me/BotFather). Обязательно нажмите у него **/start**, иначе он не сможет вам писать.
4. **Ключ DeepSeek:** https://platform.deepseek.com/api_keys. По умолчанию стоит модель `deepseek-flash` (это текущее имя Flash-модели в API DeepSeek). Модель и провайдера можно сменить в панели.
5. **CouchDB** для Obsidian Self-hosted LiveSync. Если его нет, `install.sh` поставит его сам (подробнее ниже). Если есть, бот сам создаст в нём базу. В плагине LiveSync должны быть **выключены E2E-шифрование и обфускация путей**: в зашифрованную базу писать напрямую нельзя. Бот это проверяет и в таком случае сохраняет файлы только локально.

## Установка

На сервере:

```bash
sudo apt-get install -y git && git clone https://github.com/puleglo/studybot.git ~/studybot
```

```bash
cd ~/studybot && sudo bash deploy/install.sh
```

```bash
studybot setup
```

```bash
sudo systemctl enable --now studybot
```

**CouchDB.** Если на сервере его нет, `install.sh` предложит установить. Скрипт поднимет CouchDB в Docker, настроит его под LiveSync (CORS, лимиты, обязательная авторизация), сгенерирует пароль, создаст базу `obsidian` и пропишет доступ в конфиг бота. Затем он спросит, как Obsidian будет подключаться к базе:

1. По домену с HTTPS через Caddy. Рекомендуется, и только так подключится мобильный Obsidian. Нужен домен, который указывает на сервер, и свободные порты 80/443.
2. Только локально. Доступ снаружи вы настроите сами.
3. Открытый порт 5984 без HTTPS.

**Занятые порты.** Перед установкой скрипт проверяет, свободны ли нужные порты, и при конфликте выбирает другие:

| Порт | Если занят |
|---|---|
| 5984 (CouchDB) | берётся первый свободный из 5985–5999, бот получает нужный адрес автоматически |
| 443 (HTTPS) | HTTPS поднимается на 8443 (или следующем свободном), сертификат выпускается через порт 80 |
| 80 | не страшно: сертификат выпускается через 443 |
| 80 и 443 сразу (стоит nginx/apache) | Caddy не ставится, CouchDB слушает только localhost, а скрипт выводит готовый блок `location` для вашего nginx |

Если включён UFW, нужные порты открываются в нём автоматически. Выбранные порты сохраняются в `couchdb.env`, так что при повторном запуске и обновлении они не меняются.

В конце скрипт выведет URI, логин, пароль и имя базы для настройки LiveSync в Obsidian. Повторно их можно посмотреть командой `sudo cat /opt/studybot/data/couchdb.env`. Отдельно скрипт запускается так: `sudo bash deploy/couchdb.sh`.

Мастер `setup` спросит ключи, войдёт в аккаунт (код придёт в Telegram), покажет ваши группы для выбора и проверит API и CouchDB.

## Обновление

```bash
studybot update
```

Команда скачивает новую версию с GitHub (`git pull`), показывает список изменений, переустанавливает код и зависимости и перезапускает сервис. Настройки, сессия и база в `/opt/studybot/data` не затрагиваются. Если новых изменений нет, она так и скажет. Принудительная переустановка: `studybot update --force`.

То же самое есть в панели: пункт **[9] Обновить программу**.

## Панель (только через SSH)

```bash
ssh user@vps -t studybot
```

Что есть в панели:

- **Чаты:** добавить из списка ваших групп или по ID, включить/выключить, удалить. Новый чат сразу догружается с начала дня.
- **LLM / API:** несколько провайдеров (DeepSeek, OpenRouter, OpenAI, любой OpenAI-совместимый), выбор активного, смена ключа и модели, проверка запросом.
- **Сводка:** время, часовой пояс, «прислать сейчас», последняя сводка.
- **Предметы**, **Материалы и Obsidian** (настройки CouchDB, лимит размера файла, локальная копия), **Telegram** (перелогин, токен бота), **логи**, **перезапуск**.

Изменения применяются на лету, перезапуск не нужен. Сервис ничего не слушает в сети, поэтому открывать порты не надо.

Можно сделать отдельный SSH-ключ, который открывает сразу панель и больше ничего не позволяет. Для этого в `~/.ssh/authorized_keys` на сервере допишите перед ключом:

```
command="/usr/local/bin/studybot panel",no-port-forwarding,no-X11-forwarding,no-agent-forwarding ssh-ed25519 AAAA...
```

## Где что лежит (`/opt/studybot/data`, права 700)

| Файл | Что это |
|---|---|
| `config.json` | все настройки и ключи. **Внутри строка сессии, то есть полный доступ к аккаунту Telegram. Никому не отдавайте.** |
| `studybot.db` | история сообщений, список материалов, сводки |
| `materials/` | локальная копия всех материалов (бэкап, даже если CouchDB недоступна) |
| `studybot.log` | лог (также `journalctl -u studybot -f`) |

## Замечания

- **Регистр путей LiveSync:** бот определяет настройку «Handle files as Case-Sensitive» автоматически по базе. Если в Obsidian появятся дубли файлов, задайте её вручную: «Материалы и Obsidian → настройки CouchDB → учёт регистра».
- **Расход токенов:** на каждый файл или сообщение-кандидат уходит один короткий запрос к LLM, на сводку один запрос на чат. Очень длинные дни режутся на части.
- **Риск для аккаунта:** юзербот, который только читает, — это стандартный и малорисковый сценарий. Всё же не запускайте одну и ту же сессию на нескольких серверах сразу.
